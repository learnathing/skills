# 閱讀入口範例

這是合成的開發測試資料，不是使用者上傳的項目，也不是實際驗證結果。目的是示範如何讓隱藏資料夾中的文件仍能從可見入口找到。

| 要回答的問題 | 權威文件或現況 |
| --- | --- |
| 返回時哪些資料會改變？ | [導覽規則與狀態圖](.scratch/navigation.md#navigation-contract) |
| 這張票已完成了什麼，還缺什麼？ | [工單目前狀態](.scratch/ticket.md#current-state) |
| 為什麼選這個方案？有哪些尚未測試？ | [比較決策與證據限制](.scratch/decision.md#decision) |

入口只索引來源，不在這裡再維護一份狀態表。示例圖保留 Mermaid 原始碼與完整文字對照；本資料包不宣稱已在所有 Markdown 閱讀器完成渲染驗證。
