# 比較方案，但不把未測試寫成失敗

合成示例，沒有實際效能測量。此文件示範決策表，不應被當成產品或工具推薦。

## Decision

本示例選擇方案 C。示例中的本機檢查顯示 A 未符合指定條件，C 符合；B 尚未測試。因此不能把結論寫成「只有 C 可行」。

| 方案 | 證據狀態 | 在本示例中的處置 |
| --- | --- | --- |
| A | 本機檢查未符合指定條件 | 不採用這個已測組態，不推論所有組態都失敗 |
| B | not run | 保留未知，不畫成零分或紅色失敗 |
| C | 本機檢查符合指定條件 | 本次採用，不表示生產環境已驗證 |

沒有真實數據、單位或共同工作負載，這裡不畫效能長條圖。後續取得實際測量後，才可比較數值、標明不確定性及測量範圍。
