# Living artifacts and optional visuals

Status: development scenarios, not executed human-comprehension or agent-outcome evidence.

Use synthetic fixtures or separately authorized anonymized material. Do not publish a private project archive to the skills repository. The examples in `fixtures/artifact-evolution/` are synthetic and explicitly label invented evidence states.

## Compare without changing the requirement

Use matched source decisions and preserve all conditions, negative cases, scope and evidence limits. Randomize artifact order across readers or use equivalent unseen tasks to reduce learning effects. Compare the previous artifact template, the revised rules-first template, and that same revised content with a targeted visual. Include a no-skill baseline for agent generation. Do not compare a complete diagram to incomplete prose and call the difference a visual benefit.

| Reader task | What to measure |
| --- | --- |
| Explain whether outline clicks create history and what a missing return target does | Correct behavior and exception recall |
| Decide whether implemented but unreviewed work is complete | Mistaken readiness/completion claims |
| Detect a requirement contradicted by an implementation exception | Conflict detection, not smooth prose preference |
| Explain why an option was chosen when one alternative was not run | Whether uncertainty survives the summary |
| Find the current definition of a constraint from a ticket | Correct source and revision, broken links and navigation cost |
| Identify a current limitation formerly buried in Comments | Recovery of current state rather than historical guessing |
| Compare table-only, diagram-plus-table, and diagram-only navigation explanations | Comprehension, omitted branches, and rendering/accessibility limits |

Record comprehension accuracy, missed exceptions and unsupported certainty. Reading time, document opens and stated preference are secondary diagnostics. Do not invent an empirical pass threshold from a word or node count. Independent developer reading is distinct from an agent cold read.

## Behavioral regression cases

Keep original source and approval gates. Test a ready draft, a partially implemented ticket, all-checked criteria with outstanding independent review, a reopened issue, an obsolete definition in Comments, and a changed shared constraint across two current scopes. The generator must not reset live work to ready, infer independence from a green suite, erase history, or silently accept a new product exception.

A source unavailable to the receiving session stays an explicit gap. Verify plain links, hidden-directory entry points, Unicode/renderer-dependent anchors, a stale rendered diagram and a view with a missing error edge. An unsupported renderer must leave usable text and an honest limitation, not a new website installation.

The deterministic tests exercise validator phases, identity checks, and supported local links. They do not evaluate source authority, actual human understanding, Mermaid rendering, or an agent's adherence to these rules. Retain raw results and limitations before making any outcome claim.
