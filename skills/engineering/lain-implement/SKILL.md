# Implement

Implement one bounded issue or settled request. Use the user's actual source, scope and authority; the invocation does not authorize unrelated cleanup, tracker changes, push or deployment. A request for several independently owned tickets uses separate bounded execution contexts rather than combining their contracts implicitly.

Call the Skill tool with "lain-implementation". Supply the original issue, spec or conversation decision handoff, applicable repository-action authority and any caller-provided review budget. Follow its complete protocol for the pre-existing worktree baseline, technical readiness, source recovery, vertical slices, evidence, independent review, blocker convergence and commit.

The shared discipline is the sole owner of those gates. Do not replace it with TDD alone, duplicate a reduced checklist here, or treat a missing shared skill as permission to skip checks. Report its actual completion state, evidence and unmet obligations without upgrading an incomplete or non-independent review to PASS.
